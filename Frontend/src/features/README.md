# Features por dominio

Crear una carpeta solo cuando comience su módulo: `account-request`, `auth`, `notebooks`, `documents`, `batches`, `human-review`, `quota`, `chat` y `dashboard`, o los nombres que establezca la terminología aprobada.

Cada feature puede añadir `components`, `schemas`, `services`, `types`, `hooks` y `tests` según necesidad real. No anticipar implementación de módulos futuros.
