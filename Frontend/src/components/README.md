# Componentes compartidos

- `ui/`: primitivas visuales accesibles y realmente reutilizadas.
- `layout/`: cabecera, navegación, contenedores y estructura transversal.
- `feedback/`: loading, vacío, error y confirmaciones compartidas.

No colocar aquí lógica específica de una feature ni crear un design system amplio antes de disponer de mockups definitivos.
