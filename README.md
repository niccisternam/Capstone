# Sistema Web para el Procesamiento Inteligente y Centralización de Documentos Tributarios

> Proyecto de Portafolio de Título (APT) – Duoc UC  


---

## 📌 Descripción del Proyecto
Plataforma web interna orientada a la centralización, digitalización y procesamiento automatizado de documentos tributarios de compra (facturas, boletas) y cotizaciones mediante el uso de Inteligencia Artificial multimodal. Incluye un módulo de validación asistida (*Human-in-the-loop*), panel de métricas de gasto en CLP y asistente conversacional.
