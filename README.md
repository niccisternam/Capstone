# Sistema Web para el Procesamiento Inteligente y Centralización de Documentos Tributarios

> Proyecto de Portafolio de Título (APT) – Duoc UC  


---

## 📌 Descripción del Proyecto
Plataforma web interna orientada a la centralización, digitalización y procesamiento automatizado de documentos tributarios de compra y venta (facturas, boletas) mediante el uso de Inteligencia Artificial multimodal. Incluye un módulo de validación asistida (*Human-in-the-loop*), panel de métricas de compras y ventas en CLP calculadas directamente desde la base de datos y asistente conversacional.

## 🛠️ Stack Tecnológico Proyectado
* **Frontend:** Next.js (React) + TypeScript, Tailwind CSS
* **Backend:** Node.js (Express + TypeScript, Prisma ORM) – Arquitectura REST
* **Base de Datos:** Relacional (PostgreSQL en Supabase), sin ETL ni Data Warehouse
* **IA:** Google Gemini vía API (JSON estructurado)
